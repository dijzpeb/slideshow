旅の写真スライドショー

Google ドライブのフォルダに写真や動画を入れるだけで、撮影した順にスライドショーにします。

2. ドライブへの接続方法

OAuth クライアント ID

3. 表示の設定（任意）
はじめての方へ：準備の手順
  1. Google ドライブに旅行用のフォルダを作り、写真・動画を入れます（日ごとのサブフォルダに分けても OK）。
  2. Google アカウントでログインする場合：Google Cloud コンソールで「Google Drive API」を有効にし、OAuth クライアント ID（ウェブアプリケーション、承認済みの JavaScript 生成元にこのページのアドレス）を作成して上の欄に入力します。
  3. API キーを使う場合：フォルダを「リンクを知っている全員（閲覧者）」で共有し、Google Drive API を有効にしたプロジェクトで API キーを作成して入力します。
  4. フォルダの URL を貼り付けて「スライドショーを開始」を押します。

写真は撮影日時（EXIF）、動画は動画ファイル内の撮影日時で並べます。見つからない場合はファイル名やドライブ上の日時から推定します。

キーボード操作：Space 再生/一時停止、←→ 前/次、F 全画面、M ミュート、G 一覧

写真はこのブラウザと Google ドライブの間だけでやり取りされ、他のサーバーには送信されません。

撮影時刻がずれている？ カメラごとに補正する

カメラの時計を日本時間のままにしていた場合などは、そのカメラの写真だけ時刻をずらして正しい順番にできます（例：日本時間のままのカメラをフィンランド夏時間に合わせるには −6 時間）。
